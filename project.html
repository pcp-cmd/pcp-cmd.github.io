01 / LEARNINGWindows · 本地学习库

Aleksi Workbench

把精读、摘录、卡片和复习接在一起，让学习记录留在自己的 Markdown 文件里。

以本地学习库为中心，沿着“今日学习 → 精读 → 卡片 → 主题飞轮 → 复习”组织工作。Markdown 保存原始记录，索引和缓存可以重新生成。

  • 精读材料、整理摘录与卡片，回到主题飞轮和今日复习。
  • 保留学习诊断和证据验证入口。
  • 创建、选择、迁移与备份自己的本地学习库。

当前状态 源码版本 0.1.5-rc.1，为 Windows 10/11 x64 的未签名预览；公开 Release 中保留 0.1.4 预发布版。

02 / INTERFACE浏览器 · 单文件 HTML

Vibe Front-End Tuner

把“间距舒服一点”“卡片轻一点”变成可以调节、复制和复用的视觉参数。

拖动滑杆，同时观察产品页、仪表盘和表单。选好效果后，把 CSS Token 或提示词参数交给前端开发工具，让下一次修改有具体依据。

  • 调整页面宽度、区块与卡片间距、字号和行高。
  • 调整圆角、阴影、描边和颜色温度。
  • 切换三种界面预览，复制 CSS 和提示词参数。

当前状态 单文件工具；下载仓库后打开 index.html 即可使用，无需安装依赖。

03 / EVERYDAYAndroid · Jetpack Compose

CoolCat — TodoApp

把待办、重复计划、关联任务和系统日历放在同一个任务工具里。

用分类和时间线查看任务，给任务设置优先级、截止日期与提醒，也能把有联系的任务连在一起。

  • 管理任务与一级子任务，使用两级分类和标签。
  • 按日、周、月或年重复；完成后创建下一次任务。
  • 关联任务、同步系统日历，并以 JSON 备份和恢复数据。

当前状态 Android 8.0 及以上的源码项目；构建与运行步骤见仓库说明，尚无 GitHub Release。
