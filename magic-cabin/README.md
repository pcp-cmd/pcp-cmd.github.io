# 书房 · 黑白空间

基于用户提供的 `line-art-style-magic-cabin-main.zip` 修改。继续使用原项目的 Three.js r128、原生 JavaScript、单个场景 IIFE、几何素材、声音与物件动画。

## 改造版预览

书房现在是主网站的一部分。在此目录运行 `node server.cjs`，访问 `http://127.0.0.1:4188/`，会进入 `/magic-cabin/index.html`。服务同时提供父目录的网站文章和共享脚本，运行页面不需要安装依赖。

也可以在网站根目录运行 `npm run dev`，访问 `http://127.0.0.1:4177/magic-cabin/index.html`。发布时从网站根目录运行 `npm run pack:public`，使用生成的 `dist/public`。书房文件夹依赖主网站资源，不能再单独复制出去运行。

## 空间改造

- 黑白材质、平整墙板、深灰屋顶与淡灰楼板，保留原门窗洞口。
- 默认从敞开的两面观察房屋，便于看见两层陈设。
- 书架移到一楼开放侧，并同步原有碰撞体；床的位置与书桌视觉略作调整。
- 室外森林保留原几何，线条淡化，让室内成为视觉中心。
- 沿用原来的视角、漫游、天气、昼夜、声音、史莱姆、门窗和魔法系统。

`cabin-design.js` 集中管理颜色、书架位置、床的位置与默认相机参数。墙体和家具仍在原 `index.html` 的构造段中生成。

## 书架与实体书

点选场景里的书，或先点下方“书架”靠近，再点书脊。键盘也可以在书架视角按 Enter 打开第一本。

书架继续用原 `regMagic` 注册点击，通过原 `out / cur / vel` 状态抽出书本。阅读器有双页、书脊、纸张纹理、纸页厚度、正反两面与翻页阴影。点选页边、拖动纸页或使用方向键翻页。短拖动会让纸张弹回；第一页与末页有翻页边界。合上书或按 Esc 回到场景，书本通过原动画归位。

窄屏显示单页，旋转屏幕后按正文位置重新分页；同一段文字可能换到不同页码。阅读进度保存在本机；阅读时拦住小屋移动按键。系统开启减少动态效果时，翻页直接切换。

36 本书是当前一批文章的展示位置。文章超过 36 篇后可以换批，也可以通过标题、简介、标签搜索，按长文 / 短记筛选和按日期排序。每本书打开对应文章的完整正文，分页由实际纸页尺寸决定；“连续阅读”进入网站原文章阅读页。

正式内容共用网站根目录的 `site-data.js`。把 Markdown 正文放入 `content/`，图片等资源放入 `assets/`，然后在 `ALEKSI_SITE.writing` 中登记已确认条目，例如：

```js
{
  title: '文章标题',
  description: '文章简介',
  date: '2026-10-05',
  type: 'long', // 或 note
  tags: ['主题'],
  source: 'content/writing/my-article.md',
  approved: true
}
```

Writing 列表、原文章页与书房使用同一个 `source`，无需再为实体书维护另一份正文或手工填写 `pages` 数组。添加或更新文章后，在网站根目录运行 `npm run build`，同步生成文章索引与离线正文包。`book-data.js` 只保存每批 36 个书位及本地样文配置。

目前正式 Writing 列表为空，尚未添加用户正式文章。仅本地预览会显示网站既有排版样文；公开环境不显示样文，正式列表为空时展示待添加状态。

阅读交互参考 [NIKUKIKAI 的实体书页面](https://nikukikai.art/null2)。其双页、书脊两侧的旋转原点和层叠纸张结构通过浏览器实际观察；本项目自行实现翻页代码。

## 浏览器检查

安装开发依赖后运行 `npm run qa:browser`。检查默认使用本机 Microsoft Edge，也可通过 `CABIN_BROWSER_CHANNEL=chrome` 选择 Chrome。`CABIN_PLAYWRIGHT_MODULE` 可指向已有 Playwright 安装，`CABIN_QA_OUTPUT` 可指定截图目录。提供原版 HTML 路径作为 `CABIN_ORIGINAL_HTML` 时，会对比原版与改造版的物件注册数量。

验证记录与边界见 `DESIGN-NOTES.md`。脚本通过浏览器真实点选 3D 书脊、按键、页边点击和拖动操作执行检查；观测接口、两篇测试文章索引及 Markdown 正文仅注入测试响应，不会写入正式内容。运行结果写入截图目录下的 `scene-verification.json`。文件夹中的 `verification.json` 是第一轮场景改造的历史记录。

## 原项目说明（原文保留）

一个线稿风格的 3D 魔法小屋。

[页面预览](https://yibi2333.github.io/line-art-style-magic-cabin/)

操控一只软软的史莱姆在魔法小屋里生活

## 使用

- **HTML**—— 单HTML页面实现
- **Three.js r128**—— 场景、相机、几何体与渲染
- **原生 JavaScript** —— 单个 HTML 文件、单个 IIFE
- **自定义 GLSL 着色器** —— 全局 FILL 材质实现自然光效：壁炉炉火、二楼魔法吊灯、9 处室内点光源（坩埚魔火、魔法阵、暖桌、水晶球、蜡烛、星象仪等），物品随昼夜与天气自然变暗、被光照亮
- **Canvas 动态贴图** —— 路牌、便签、黑板、画像等可编辑内容
- **Pointer Lock API** —— 第一人称鼠标视角

## 玩法

- 三种视角切换：固定 / 第三人称 / 第一人称
- 昼夜循环，时刻与时间流速可调
- 七种天气：晴、多云、雾、雨、暴雨、雪、暴雪，支持随机轮换
- 室内光照可交互：壁炉、吊灯可点燃熄灭，光源强度随火焰闪烁
- 可编辑内容：路牌文字、便签文字、墙上画像的图片链接
- 楼内陈设：原木餐桌、暖桌、书架、大魔女坩埚、塔罗牌桌、大床、书桌、星象仪、月光盆栽……

## 操作

| 按键 | 动作 |
| --- | --- |
| WASD / 方向键 | 移动 |
| Shift | 疾跑 |
| 空格 | 跳跃（可以跳上桌椅床凳） |
| E | 交互（门窗、壁炉、编辑文字） |
| 1 / 2 | 空手 / 魔杖 |
| 鼠标 | 视角（第三 / 第一人称） |
| Esc | 退出鼠标锁定 |
| 右上角 ● | 菜单 |

移动端：虚拟摇杆移动，右侧按钮为跳跃 / 交互 / 疾跑 / 施法。
