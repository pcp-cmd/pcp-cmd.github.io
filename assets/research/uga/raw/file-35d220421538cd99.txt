# 0. Frozen U1–U4 input

Let \(D\) be a finite-dimensional basic \(k\)-algebra. U4 supplies primitive vertices \(i,j\) and a simple left module \(L_z\) such that

\[
\operatorname{Tor}^D_n(R_i,L_z)\neq0
\]

for arbitrarily high \(n\), while

\[
e_zDe_i=0,
\qquad
e_zDe_j\neq0,
\qquad
j\neq i.
\]

The desired fixed-source switch was

\[
i\rightsquigarrow z\to j
\Longrightarrow
j\rightsquigarrow z.
\]

U1–U4 source-side dévissage, augmentation transfer-or-kernel descent, context/restartability failures, and bare singular-map failures are frozen and not reproved here.

\[

For finite-dimensional modules,

\[
\mathbb D\operatorname{Tor}^D_n(X,L_z)
\cong
\operatorname{Ext}_{D^{op}}^n(X,\mathbb DL_z).
\]

This confirms the right-side formulation but exposes a slot mismatch: the Peirce datum controls \(z,j\), while the desired detector switch concerns \(i,j\).

## Quotient / localization

Define

\[
\mathcal K_z^R=\ker\mathfrak E_z,
\qquad
\mathcal Q_z^R=D_{\rm sg}(D^{op})/\mathcal K_z^R.

## Set problem \(\to\) Peirce product

Define

\[
\Sigma_z=\{v:\mathfrak E_z(R_v)\neq0\}.

\[

\[

## Local-to-global

A finite-length right module whose simple factors are all source-\(z\) visible is tail-null if all those simple factors are tail-null.

## Infinite descent

# 2. Tail category

Use cohomological indexing.

Let

\[
D^-_{\rm fd}(k)
\]

be complexes with finite-dimensional cohomology in each degree and zero cohomology in sufficiently large positive degrees, and let

\[
D^b_{\rm fd}(k)
\]

be its bounded-cohomology thick subcategory.

Define

\[
\boxed{
\mathsf{Tail}(k)
=
D^-_{\rm fd}(k)/D^b_{\rm fd}(k).
}
\]

An object is zero in \(\mathsf{Tail}(k)\) exactly when its cohomology is bounded.

# 4. Source-relative tail detector

Fix \(L_z\). Define on \(D^b(\mathrm{mod}\text{-}D)\)

\[
F_z(X)=X\otimes_D^{\mathbf L}L_z
\]

and

\[
\mathfrak E_z^{\,b}
=
Q_{\rm tail}\circ
(-\otimes_D^{\mathbf L}L_z).

For an ordinary right module \(X\),

\[
H^{-n}(F_z(X))
=
\operatorname{Tor}^D_n(X,L_z).
\]

Hence

\[
\boxed{
\mathfrak E_z^{\,b}(X)\neq0
\iff
\operatorname{Tor}^D_n(X,L_z)\neq0
\text{ for arbitrarily high }n.
}
\]

If \(P\in K^b(\mathrm{proj}\text{-}D)\), then \(P\otimes_DL_z\) is bounded, so perfect objects vanish.

Therefore the functor factors through

\[
\boxed{
\mathfrak E_z:
D_{\rm sg}(D^{op})
\to
\mathsf{Tail}(k).
}
\]

For every primitive \(v\),

\[
\boxed{
\mathfrak E_z(R_v)\neq0
\iff
\operatorname{Tor}^D_n(R_v,L_z)\neq0
\text{ arbitrarily high}.
}
\]

# 6. Recurrent Betti support

Let

\[
P_n(L_z)
=
\bigoplus_v(De_v)^{\beta_{n,v}}
\]

be the minimal left projective resolution of \(L_z\).

Minimality kills differentials after tensoring with \(R_v\), so

\[
\operatorname{Tor}^D_n(R_v,L_z)
\cong
R_v\otimes_DP_n(L_z).
\]

Therefore

\[
\boxed{
\Sigma_z
=
\{v:\mathfrak E_z(R_v)\neq0\}
=
\{v:\beta_{n,v}>0\text{ for arbitrarily high }n\}.
}
\]

Thus \(\Sigma_z\) is the recurrent Betti support of \(L_z\).

A source-\(z\) visible recurrent pair exists iff

\[
e_zDe_{\Sigma_z}\neq0.
\]

Hence source-\(z\) failure has the exact normal form

\[
\boxed{
\Sigma_z\neq\varnothing,
\qquad
e_zDe_{\Sigma_z}=0.
}
\]

This is the **Source-Relative Peirce Dead-Zone** condition.

\[

\[
\Omega^mR_i\simeq R_i[-m]

\[
R_i[-m]\simeq R_j

\[
\boxed{

\mathfrak E_z(R_j)\neq0.

The same holds for an inclusion

\[
R_j\hookrightarrow\Omega^mR_i

with detector-null cokernel.

Thus detector switching works when \(R_j\) is isolated inside the right syzygy orbit of \(R_i\) modulo detector-null error.

No theorem derives this from \(e_zDe_j\neq0\).
