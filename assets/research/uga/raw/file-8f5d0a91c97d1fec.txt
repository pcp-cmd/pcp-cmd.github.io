# 关键顶点的偏序支撑为何仍不足

2026-09-23。接续 [任意 N 主路线](N-Vertex-Main-Route.md) 的左右支撑检测。

**状态：本稿给出抽象矩阵族，不是代数族，也不是 Universal Gap A 反例。** 它证明，下述已经获得的支撑必要条件，即使再加“关键支撑是偏序、左右关键标签相同”，仍不足以推出 H=0。任意大小的矩阵构造有直接证明，有限程序只作核对。尚未独立核验。

## 1. 检验的是哪一条推断

原代数的 Boolean Peirce 矩阵为 C_ki=1 当且仅当 e_kAe_i≠0；persistent Tor 矩阵为 H_ij=1 当且仅当 Tor_n(R_i,L_j) 无穷多次非零。

在本次候选推断中，假设无限 pd 左 simples 与无限 pd 右 simples 的标签集合相同，记为 V；以下 C、H 都限制到 V。于是 H 的每一行、每一列非空。没有 infinite supported Tor 时必须有
\[
H_{ij}=1\Longrightarrow C_{ji}=0.
\tag{1}
\]

已有的左侧分量检测要求：对 H_ij=1，取 i 所在的 H 第 j 列诱导 C-无向连通分量 K，存在 q∈K、k 满足
\[
H_{ik}=C_{kq}=1.
\tag{2}
\]
右侧有转置版本。另有递归覆盖检测：先分解无向连通分量；若某标签 i 的 C 列覆盖当前集合全部标签的 C 列，则可删除 i 并继续。

这些规则仍能用于上述关键限制。因为被略去的左 simples 有限 pd，不会贡献固定右 simple 的无穷 Tor；右侧同理。投射项间的 Hom 则由保留的 Peirce 分量准确给出。

**不能在这个限制上自动应用全局 protected-corner 规则。** V 内没有双向邻居不意味着整个 A 中没有经 V 外顶点返回的乘法，不能据此把 e_iJe_i 设为零。本稿保留未知的 local radical。若把下面的偏序 C 当作整个代数的 Peirce 矩阵，其他全局定理可能立即排除它；那不是本次关键限制的问题。

## 2. 任意 m≥8 的模式

取 p,q≥2，令
\[
V=\{a,b,u,v\}\sqcup\{a_1,\ldots,a_p\}
\sqcup\{b_1,\ldots,b_q\}.
\]
定义偏序的覆盖关系
\[
a<a_i<u,\qquad b<b_j<v,
\qquad a<v,\qquad b<u.
\tag{3}
\]
除此之外只加自反性和传递性。设
\[
C_{ki}=1\iff i\le k,
\qquad H_{ij}=1\iff i\not\le j.
\tag{4}
\]
因此 H 正好是 C 的转置的逐项补矩阵，(1) 自动成立。顶点数 m=p+q+4；取 p=2、q=m−6，就覆盖每个 m≥8。

注意 m 是抽象关键支撑的大小，不是已经构造出的原代数的顶点数。

## 3. 为何全部列都通过已有检测

H 第 j 列的标签集合是
\[
T_j=V\setminus\mathord\downarrow j.
\tag{5}
\]
每个 T_j 的诱导无向图都连通，且至少有两个极小元素。具体地：

| j | T_j 的极小元素 |
|---|---|
| a | b 以及全部 a_i |
| a_i | b 以及其他 a_k |
| u | 全部 b_j |
| b | a 以及全部 b_j |
| b_j | a 以及其他 b_k |
| v | 全部 a_i |

连通性可从 (3) 直接看出：前两类由共同上端 u 连接到 b 分支；第三类是以 v 为上端的星形。其他三类对称。p,q≥2 保证所有列都有至少两个极小元素。

固定 i∈T_j。由于 T_j 不可能由 i 一个元素向上生成，可取 k∈T_j 使 i≰k。于是
\[
H_{ik}=1,\quad C_{kk}=1,\quad H_{kj}=1.
\tag{6}
\]
在 (2) 取 q=k，便得到一个检测见证。并且同一论证给出 H≤H²≤HCH。

同时，任何 i∈T_j 都不覆盖 T_j 中全部标签的 C 列：若覆盖，则每个 k∈T_j 都满足 k∈supp C_i，也就是 i≤k，矛盾。因此递归覆盖规则没有第一步可走；分量规则也不能拆开这个连通集合。

## 4. 为何右侧也没有矛盾

置换 a↔u、b↔v，并固定所有中间标签，是 (3) 的序反同构。因此上面的列论证在转置后原样适用。

由此，每一行同样非空，左右分量检测及递归覆盖测试全部通过。形式上允许 D=C 作为 local radical 未知时的上界，H≤DH、H≤HD 也不会消去任何项；这不是对实际 radical 乘法的实现声明。

这完成一个精确的逻辑结论：**(1)、左右分量检测、H≤HCH、递归覆盖、左右关键标签相同，以及关键 C 为偏序，并不在纯 Boolean 层面蕴含 H=0。**

## 5. 八标签的最小展示与审计

取 p=q=2，依次编号 a,a_1,a_2,b,b_1,b_2,v,u 为 0,…,7，列 bitmask 为
\[
C=(199,130,132,248,80,96,64,128),
\]
\[
H=(254,252,250,247,231,215,134,112).
\tag{7}
\]
H 有 44 个非零位置。程序 [audit_critical_poset_pattern.py](../work/audit_critical_poset_pattern.py) 分别保存全部 88 个左右检测见证，并检查 p,q=2,…,5 的 16 个矩阵实例。结果见 [critical_poset_pattern_audit.json](../work/critical_poset_pattern_audit.json)。

程序还检查了此八标签模式的八个七标签主子矩阵，它们均被当前平衡剪枝过程消去。这只是在本例中逐一删点的结论，**没有证明所有七标签偏序都不可能，也没有证明八是全局最小值**。

## 6. 对任意 N 路线的实际影响

不能再仅凭“把关键角排成有向无圈图”宣称完成一般归纳，也不能把额外平衡条件当作修复。上述模式完全保留了这些条件。

后续证明必须加入当前矩阵没有表达的信息，例如实际前缀复形的微分、真实尾端对 Au 的全部 Tor 正交性，或相对奇点商中的具体生成关系。[Tor-Orthogonality-and-Corner-Tests.md](Tor-Orthogonality-and-Corner-Tests.md) 保留了这些对象。

本稿没有证明这些抽象模式能由潜在反例代数实现，也没有否定任何额外使用实际乘法的代数定理。Universal Gap A 仍是原来的未证目标。
