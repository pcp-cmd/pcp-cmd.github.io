# 17. VERIFIED — Four-Source Internal Incidence Barrier

Assume a collision-free strict core satisfies:

1. all eligible sources are in a finite set \(X\);
2. every source has a shared detector with another source;
3. the shared detector used for that source lies in \(X\);
4. every source has a strict purified visible carrier in
   \[
   X\setminus\{x\};
   \]
5. row-wise
   \[
   R_{xt}P^\circ_{xt}=0.
   \]

Then

\[
\boxed{
|X|\ge4.
}
\tag{17.1}
\]

### Proof for \(|X|=2\)

Let

\[
X=\{1,2\}.
\]

A shared detector internal to \(X\) must be either \(1\) or \(2\).

If it is \(1\), then the source \(1\) row contains detector \(1\), contradicting

\[
R_{11}=0.
\]

Similarly for detector \(2\).

So no two-source fully internal shared-detector core exists.

### Proof for \(|X|=3\)

Let

\[
X=\{1,2,3\}.
\]

For a fixed row \(x\), the only possible internal detectors distinct from \(x\) are the other two vertices.

Because the row must have a strict visible carrier in \(X\setminus\{x\}\) and recurrent/visible supports are disjoint, the recurrent row can contain at most one of these two vertices.

But it must contain an internal shared detector.

Hence every row has exactly one internal recurrent detector.

Thus there is a function

\[
f:X\to X,
\qquad
f(x)\neq x,
\]

such that row \(x\) uses detector \(f(x)\).

Every source must have a shared partner.

Therefore every value \(f(x)\) that occurs must occur in a fiber of size at least \(2\).

With only three sources, this forces all three rows to have the same detector value.

But then that detector vertex \(v\) satisfies

\[
f(v)=v,
\]

contradicting

\[
R_{vv}=0.
\]

Therefore \(|X|=3\) is impossible.

So

\[
|X|\ge4.
\]
