# 0. 整个项目到底在解决什么

最初对象是 Han 猜想：

\[
HH_n(A)=0\quad(n\gg0)
\stackrel{?}{\Longrightarrow}
\operatorname{gldim}A<\infty
\]

对有限维代数 \(A\)。

Kong–Liu–Shen（KLS）在 2026 年给出了 Han 猜想反例，所以项目很快从“Han 猜想真假”转向：

1. 理解 KLS 反例究竟在哪一层打破 Han 猜想；
2. 把 Han 猜想拆成更细的结构问题；
3. 进一步研究 Han 猜想之外仍可能成立的 Universal Gap A。

项目采用的两段式骨架是

\[
\operatorname{gldim}A=\infty
\overset{\mathrm{Gap\ A}}{\Longrightarrow}
A\text{ infinite }+
\overset{\mathrm{Gap\ B}}{\Longrightarrow}
HH_*(A)\text{ infinite}.
\]

因此：

- **Gap A**：无限全局维数是否强迫某个 simple-to-simple 高阶 Tor/Ext 的“可见无穷返回”；
- **Gap B**：已有 infinite \(+\) 是否必然强迫 Hochschild homology 无限出现。

后来项目真正的主目标变成：

\[
\boxed{
\operatorname{gldim}D=\infty
\Longrightarrow
\exists(i,j)\;
e_jDe_i\neq0,\quad
\operatorname{Tor}_n^D(R_i,L_j)\neq0
\text{ for infinitely/arbitrarily high }n
}
\]

这就是项目里所谓 **Universal Gap A** 的“visible recurrent simple pair”版本。

截至 **2026-10-01**：

\[
\boxed{\text{Universal Gap A 仍然 OPEN。}}
\]

但研究过程中已经得到大量结构性压缩、反例、标准型、桥梁和失败路线。

# 1. 2026-08-08 ～ 08-12：研究启动——先锁定相对 Ext/Tor 瓶颈

\to

真正的技术瓶颈被识别为：

\[

# 3. 2026-08-18：第一次完整结构地图

08-18 的 handoff 是早期研究第一次真正形成“数学理论地图”。

## 3.1 Serre–Probe / Nakayama–Serre 框架

取 \(A\) 的最小 \(A^e\)-projective resolution：

\[
P_\bullet\to A
\]

并考虑 Nakayama-twisted complex：

\[
K_\bullet=\nu_{A^e}(P_\bullet).
\]

研究中整理出：

\[
H_n(K_\bullet)
\cong
\operatorname{Tor}_n^A(DA,DA)
\cong
D\operatorname{Ext}_{A^e}^n(A,A^e),
\]

以及链级 identification：

\[
\operatorname{Hom}_{A^e}(DA,K_\bullet)
\cong
A\otimes_{A^e}P_\bullet.
\]

这部分后来被称为 **Serre–Probe Framework**。

它的重要性是：

> 把 Hochschild、bimodule Ext、Nakayama/Serre 结构放进一个共同链级框架。

但当时已经明确：

**它不是 Universal Gap A 的最后桥梁。**

## 3.2 Recurrent-top lemma / Single-top obstruction

假设 \(A\) hypothetical fails Gap A，\(S_x\) 是 infinite-pd simple。

高阶 syzygy 的 top 必须避开 \(x\)：

\[
e_x\Omega^n(S_x)=0
\qquad(n\gg0).
\]

令

\[
T_n(x)=\operatorname{supp}\operatorname{top}\Omega^n(S_x).
\]

若某个 top vertex \(y\) 在后续 resolution 中 recurrent，则高阶 Ext 会反复出现：

\[
\operatorname{Ext}_A^j(M,S_y)\neq0
\]

对无穷多个 \(j\)。

通过 composition-series dévissage，会出现某个 simple \(S_z\) 具有持久

\[
\operatorname{Ext}_A^{j_t}(S_z,S_y)\neq0.
\]

但 Gap-A failure 的 one-way law 又要求：

\[
zAy=0.
\]

另一方面 \(z\) 作为 \(M\) 的 composition factor，必须被某个 top \(y'\) 生成：

\[
zAy'\neq0.
\]

于是如果 top 只有一个 simple type，就矛盾。

得到：

\[
\boxed{
|\operatorname{supp}\operatorname{top}\Omega^n(S_x)|\ge2
}
\]

这就是：

\[
\boxed{\textbf{single-top impossible}}
\]

或

\[
\boxed{\textbf{Gap-A failure forces a multi-top derangement}.}
\]

## 3.3 至少两个 infinite-pd simples

如果只有一个 infinite-pd simple \(S_x\)，而 Gap A 又失败，那么 sufficiently high syzygy 必须避开 \(S_x\)。

此时它的 composition factors 全是 finite-pd simples，于是整个 syzygy 也 finite-pd，反推：

\[
\operatorname{pd}S_x<\infty,
\]

矛盾。

因此 hypothetical Gap-A failure 至少需要多个 infinite-pd simple。

## 3.4 三顶点与四顶点第一次分岔

当时项目一度得到：

\[
|Q_0|\le3
\Rightarrow
\text{Gap A}
\]

的高置信度候选。

甚至曾短暂尝试推到 \(v\le4\)。

但四顶点结论很快被撤回。

原因是：

- all-infinite 4-vertex case 的组合压缩较强；
- 但 **3 infinite + 1 finite hub** 时，
- 以前用了类似 mutual-dumbbell 的 finite-injective-dimension 行为；
- finite-pd hub 并不自动 finite-injective-dimension。

所以：

\[
\boxed{
v=4\text{ 的 finite-hub case 成为真正缺口。}
}
\]

## 3.5 第一个全局 obstruction：multi-top Ext–Peirce derangement

研究把剩余困难概括为：

\[
\boxed{
\textbf{multi-top Ext–Peirce derangement}
}
\]

即：

- 高阶 syzygy 必须躲开原 simple；
- 又必须 multi-top；
- derived/Ext recurrence 与 ordinary Peirce support 发生错位；
- 单纯 finite graph / pigeonhole 不够，因为 relations 可以杀死长路径 composite。

## 3.6 已明确禁止继续使用的错误路线

### REFUTED / 不可直接使用

1. periodic module \(\Rightarrow\) simple self-Ext；
2. singular/Tate self-map \(\Rightarrow\) ordinary Ext；
3. 删除顶点 quotient 自动是 homological epimorphism；
4. naked graph cycle \(\Rightarrow\) homological return；
5. \(v\le4\) 已解决；
6. \(A^{op}\) 的结论未经 convention 审计直接搬回 \(A\)。

这些负结果后来成为 MRS 的“冻结负知识”。

# 4. 2026-08-22 ～ 08-23：eventual-periodic 主线与重大 convention 修正

## 4.1 08-22：前沿从 periodicity 转成 Peirce-compatible return

此时研究认识到：

当时大量论证只覆盖 **eventually bimodule-periodic** 的 subclass。

因此不能把它偷换成 Universal Gap A。

## 4.2 08-23：opposite-side convention 纠正

这是早期研究最重要的一次纠错。

正确关系是：

\[
\Lambda\text{ infinite co}+
\iff
\Lambda^{op}\text{ infinite }+,
\]

而不是

\[
\Lambda\text{ infinite }+
\iff
\Lambda^{op}\text{ infinite }+.
\]

所以即使已经证明：

\[
A_{\mathrm{KLS}}^{op}\text{ infinite }+,
\]

也只能推出：

\[
A_{\mathrm{KLS}}\text{ infinite co}+.
\]

不能推出原 \(A_{\mathrm{KLS}}\) infinite \(+\)。

因此 KLS 分类重新开放：

- **KLS-A**：原 \(A\) 不是 infinite \(+\)  
  \(\Rightarrow\) KLS 本身就是 Gap-A failure；
- **KLS-B**：原 \(A\) 是 infinite \(+\)  
  \(\Rightarrow\) KLS 是 Gap-B failure。

## 4.3 Buried-Boundary Return Problem

这一时期出现了一条非常清楚的桥梁问题：

\[
\boxed{
\begin{array}{c}
\text{self-avoiding genuine periodic orbit}\\
+\text{persistent Ext-to-projective defect}\\
+\text{vertex-minimal deletion}\\
\Downarrow ?\\
e_x\Omega_A^m(S_x)\neq0
\text{ infinitely often}.
\end{array}
}
\]

项目称其为：

\[
\boxed{\textbf{Buried-Boundary Return Problem}}
\]

它已经预告了后来的 U1–U8：

> 总能看到某种“深处的 defect”，但怎样把它重新拉回 ordinary visible simple pair？
