## 2. Explicit algebra and all FULL kernels

with LEFT Kupisch lengths c=(4,3,3). Ae_i has paths p_(i,l), 0<=l<c_i,
starting at i and ending at i+l. Thus

P0: (L0,L1,L2,L0),

P2: (L2,L0,L1).

The quotient M(i,l) of Ae_i retaining lengths0,...,l-1 has literal FULL kernel

    Omega M(i,l) = M(i+l,c_i-l),

when l<c_i. This follows by right multiplication by the first retained-kernel
path p_(i,l): all paths of lengths l,...,c_i-1 are obtained bijectively from the
basis of M(i+l,c_i-l), and products with all radical basis paths agree. This is
a full A-linear module isomorphism over any field, not a head/dimension guess.

Apply it:

    Omega L0 = P1;
    Omega L1 = M(2,2),   Omega M(2,2) = L1;
    Omega L2 = M(0,2),   Omega M(0,2) = M(2,2).

projective radical. Therefore

    pd_A L0=1,   pd_A L1=pd_A L2=infinity.

In particular Omega_A^(2r)L1=L1, and beta_11(2r)=1 for every r>=1. A has
infinite global dimension and is already ordinary-positive: it is NOT bad and
NOT a Universal Gap A counterexample.

## 4. Cover enlargement cannot make a strict finite block

the smallest projective-cover-closed LEFT block containing F is {0,1,2}.

## 7. Exact finite-error repair that remains valid, with its gate

This is a reuse/general instance of C109/C111, not a new project claim. If
X has actual minimal cover0->Omega X->P->X->0 and S is an ACTUAL submodule
of Omega X with pd S=d<infinity, then the real quotient has the exact sequence

    0 -> (Omega X)/S -> P/S -> X -> 0,
    pd(P/S)<=d+1.

For every RIGHT module R, the ordinary long exact Tor sequence of
0->S->Omega X->(Omega X)/S->0 gives SAME-DEGREE isomorphisms

    Tor_n(R,Omega X) = Tor_n(R,(Omega X)/S),   n>d+1.

The quotient-cover exact sequence gives

    Tor_n(R,X) = Tor_(n-1)(R,(Omega X)/S),   n>d+2.

These preserve an actual infinite tail. A finite pd FULL kernel K of the
unrelated finite-pd module I gives no bound on a chosen S inside K: Section3
has pd K=0 but pd S=infinity. A strict C111 source descent additionally needs
the semisimple actual quotient, genuine infinite source, actual late
occurrences, and the diagonal cutoff that removes its own recurrent label.
The full cover of I alone supplies none of those source-alignment hypotheses.
