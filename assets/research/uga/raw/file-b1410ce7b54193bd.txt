# 3. Tor–Ext duality: exact orientation

Let \(R\) be a finite-dimensional right \(D\)-module and \(L\) a finite-dimensional left \(D\)-module.

Take a finite-dimensional projective resolution

\[
P_\bullet\to L.
\]

For each \(n\) there is a natural vector-space isomorphism

\[
\boxed{
D_k(R\otimes_DP_n)
\cong
\operatorname{Hom}_D(P_n,D_kR),
}
\tag{3.1}
\]

given by

\[
\Phi(\lambda)(p)(r)
=
\lambda(r\otimes p).
\]

Because all chain spaces are finite-dimensional,

\[
D_kH_n(C_\bullet)
\cong
H^n(D_kC_\bullet).
\]

Therefore

\[
\boxed{
D_k\operatorname{Tor}^D_n(R,L)
\cong
\operatorname{Ext}^n_D(L,D_kR).
}
\tag{3.2}
\]

This is the canonical formula.

# 4. Split-basic / algebraically closed specialization

Let

\[
R_i
\]

be the right simple at primitive vertex \(i\).

If \(D\) is split-basic over an algebraically closed field, then

\[
D_kR_i\cong L_i.

\[
\boxed{
D_k\operatorname{Tor}^D_n(R_i,L_z)
\cong
\operatorname{Ext}^n_D(L_z,L_i).
}
\tag{4.1}
\]

Thus:

\[
\boxed{
\operatorname{Tor}^D_n(R_i,L_z)\neq0
\iff
\operatorname{Ext}^n_D(L_z,L_i)\neq0.
}
\tag{4.2}
\]

This is the orientation used throughout the actual U5 countermodel.
