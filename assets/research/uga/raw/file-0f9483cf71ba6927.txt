# 3. 已建立的统一理论骨架：Serre–Probe Framework

这一部分是项目综合理论的重要资产，但下一个对话不要继续无限扩展它，除非它直接帮助 Gap A。

取 \(A\) 的最小 \(A^e\)-投射分解
\[
P_\bullet\to A
\]
以及 Nakayama-twisted complex
\[
K_\bullet:=\nu_{A^e}(P_\bullet).
\]

Armenta 给出：
\[
H_n(K_\bullet)
\cong
\operatorname{Tor}_n^A(DA,DA)
\cong
D\operatorname{Ext}_{A^e}^n(A,A^e),
\]
且
\[
Z_n(K_\bullet)=\tau_nA.
\]

项目中得到链级 natural identification：
\[
\boxed{
\operatorname{Hom}_{A^e}(DA,K_\bullet)
\cong
A\otimes_{A^e}P_\bullet.
}
\]

因此同一复形 \(K_\bullet\) 同时承载：
\[
\boxed{
\begin{aligned}
H_n(K_\bullet)
&=\text{Serre/Gorenstein shadow},\\
Z_n(\operatorname{Hom}_{A^e}(DA,K_\bullet))
&=HH_n^\tau(A),\\
H_n(\operatorname{Hom}_{A^e}(DA,K_\bullet))
&=HH_n(A).
\end{aligned}}
\]

解释：

- **Gap A** = singular/Nakayama tail 是否被 \(DA\)-probe 看见；
- **Gap B** = 已被看见的 \(\tau\)-cycles 是否在 stable quotient / ordinary HH 中存活；
- ordinary boundaries = injective-factorization saturation。

可定义 dead injective sector：
\[
\mathcal D_A
=
\{J\in\operatorname{Inj}(A^e):
\operatorname{Hom}_{A^e}(DA,J)=0\}.
\]

Gap-A hypothetical failure 在高阶表现为 Nakayama tail 落入这个 dead sector。

# 5. Gap A：当前最可靠新结果

## 5.1 Recurrent-top lemma / single-top obstruction

这是当前非常关键的 project-derived lemma。

设 \(A\) hypothetical fails Gap A，\(S_x\) 是 infinite-pd simple。

Armenta 的 syzygy-return / one-way criterion给出：充分大 \(n\),
\[
e_x\Omega^n(S_x)=0.
\]

等价地，高阶 top 支撑落入 dead zone：
\[
T_n(x):=
\operatorname{supp}\operatorname{top}\Omega^n(S_x)
\subseteq
Z(x)
=
\{y:xAy=0\}.
\]

取一个 sufficiently high syzygy
\[
M=\Omega^n(S_x).
\]

若某个 top vertex \(y\in \operatorname{top}M\) 在后续最小分解中 recurrent，则：
\[
\operatorname{Ext}_A^j(M,S_y)\neq0
\]
对无限多个 \(j\) 成立。

沿 \(M\) 的 composition series dévissage，存在 composition factor \(S_z\) 满足：
\[
\operatorname{Ext}_A^{j_t}(S_z,S_y)\neq0
\]
无限多次。

Gap-A one-way law 强迫：
\[
zAy=0.
\]

但因为 \(S_z\) 是 \(M\) 的 composition factor，而 \(M\) 由 top 生成，所以必有某个 top \(y'\)：
\[
zAy'\neq0.
\]

因此：

### Single-top impossible
如果 \(\operatorname{top}M\) 只有一个 simple type \(S_y\)，则 \(y'=y\)，立刻矛盾。

所以 hypothetical Gap-A failure 中，高阶 recurrent syzygy 必满足：
\[
\boxed{
|\operatorname{supp}\operatorname{top}\Omega^n(S_x)|\ge2
}
\]
在相应 recurrent tail 上成立。

这可以理解为：
\[
\boxed{
\text{Gap-A failure forces a multi-top derangement.}
}
\]

---

## 5.2 至少两个 infinite-pd simple 的结论

一个更基础的无周期引理：

若 \(S_x\) 是唯一 infinite-pd simple，而 Gap A 失败，则高阶 \(\Omega^n(S_x)\) 避开 \(S_x\)，其所有 composition factors 都是 finite-pd simples。

有限长度扩张性质给：
\[
\operatorname{pd}\Omega^n(S_x)<\infty,
\]
反推出：
\[
\operatorname{pd}S_x<\infty,
\]
矛盾。

因此：
\[
\boxed{
\text{任何 Gap-A failure 至少有两个 infinite-pd simples.}
}
\]

这个结论不需要 eventual periodicity。

进一步，在 eventual-periodic 情形，利用 periodic syzygy + recurrent-top lemma，可以压得更强：

- 高阶 periodic syzygy 不可能是 single-top；
- 高阶 periodic syzygy 不可能只含一种 infinite-pd simple type；
- hypothetical eventual-periodic failure 必须是 multi-top / multi-infinite derangement。

但“至少三个 infinite-pd simples”这一更强版本目前虽然有较强内部论证，仍应继续审计后再正式使用。

# 6. 三顶点 Gap A：当前高置信度 candidate closure

这是当前最重要的新 theorem candidate。

Armenta v1 对三顶点 hypothetical Gap-A failure 给出两个 frontier：

1. one-infinite case；
2. mutual dumbbell case。

项目当前论证：

## 6.1 one-infinite case 被排除
由上面“Gap-A failure 至少两个 infinite-pd simples”直接矛盾。

## 6.2 mutual dumbbell 被排除
Armenta 对 mutual dumbbell 给出 one-sided tail：

对某个 \(S_x\)，高阶
\[
M_x=\Omega^N(S_x)
\]
的最小 resolution tail 只沿一个 dead vertex \(w\) 方向运行；对应 hub \(S_u\) 有有限 projective dimension（原文还给有限 injective dimension）。

在这个 tail 中：
\[
\operatorname{Ext}_A^j(M_x,S_w)\neq0
\]
对所有充分大 \(j\) 成立。

但若 Gap A 失败，则：
\[
\operatorname{Ext}_A^{\gg0}(S_w,S_w)=0.
\]

而有限 projective dimension的 hub \(S_u\) 给：
\[
\operatorname{Ext}_A^{\gg0}(S_u,S_w)=0.
\]

因为 \(M_x\) 的 composition factors只来自 \(S_u,S_w\)，沿 composition series 做 dévissage，得到：
\[
\operatorname{Ext}_A^{\gg0}(M_x,S_w)=0,
\]
矛盾。

所以：
\[
\boxed{
\textbf{Gap A 对所有至多 3 个顶点的 elementary finite-dimensional algebras 成立}
}
\]

当前状态：

- **project-derived theorem candidate**
- 内部审计高置信度
- 尚未外部同行审稿
- 不宣称 novelty

# 8. Universal Gap A 当前真正障碍

Gap-A failure 的高阶 syzygy 必须：

- 避开原 simple；
- 至少 multi-top；
- 在 Ext 与 Peirce support 之间形成 derangement；
- 不能用单纯 pigeonhole / finite graph argument 直接杀掉，因为 relations 可以把长度 \(2\) 及更长 path composites 全部杀死。

可以把剩余结构叫：
\[
\boxed{
\textbf{multi-top Ext–Peirce derangement}
}
\]

其模式为：

- 对 recurrent top \(y\)，存在 composition factor \(z\)：
  \[
  \operatorname{Ext}_A^{n_j}(S_z,S_y)\neq0
  \]
  infinitely often；
- Gap-A failure 强迫
  \[
  zAy=0;
  \]
- 但 \(z\) 必从另一个 top \(y'\) 被实际生成：
  \[
  zAy'\neq0.
  \]

这就是 universal Gap A 当前最核心的“转移循环”难点。

# 9. Eventual-periodic 路线：已知 dead ends 与可用方向

## 9.1 Tate/Yoneda route 的真实缺口
eventual bimodule periodicity 可在 singular/Tate Yoneda 中产生可逆正次数 periodic class。

但 CLMS 的 finite-generation criterion需要 ordinary simple Yoneda data。

non-Gorenstein 情形中：
\[
\text{singular/Tate Ext}
\not\Rightarrow
\text{ordinary high Ext}
\]
没有现成 comparison isomorphism。

所以不能偷换成：
\[
\text{periodic bimodule}
\Rightarrow
\text{ordinary Yoneda algebra finitely generated}
\Rightarrow
\text{infinite }+.
\]

这条路线目前卡在 comparison/fidelity gap。

## 9.2 Proper quotient route 的真实缺口
若 high tail 避开 vertex \(x\)，可考虑
\[
\bar A_x=A/Ae_xA.
\]

特定 tail 可在 \(\bar A_x\) 上继续作为 projective tail。

但：
\[
A\to \bar A_x
\]
一般不是 homological epimorphism。

不能仅凭某条 tail 的 confinement 就断言 infinite \(+\) witness 从 quotient 自动 lift 回 \(A\)。

所以 minimal-counterexample induction 当前缺少 lifting theorem。

## 9.3 Singular-core idempotent reduction
令 \(e\) 为所有 infinite-pd simple vertices 之和。

finite-pd simples 被 \(e\) 杀掉，因此 \(e\) 在 Chen 意义下具有 singularly-complete 的潜力。

若还能证明：
\[
\operatorname{pd}_{eAe}(eA)<\infty,
\]
则可望得到：
\[
D_{\mathrm{sg}}(A)\simeq D_{\mathrm{sg}}(eAe).
\]

真正障碍是 cross module：
\[
eA(1-e)
\]
在 \(eAe\) 上可能具有 infinite projective dimension。

这个 cross-module obstruction 很可能是 finite hubs 真正承载 singularity 的方式。

这是一个值得继续攻的方向。

# 10. KLS 原代数 \(A\) 的 Gap-A 方向：仍未判定

非常重要：

我们已经内部封住的是：
\[
B=A_{\mathrm{KLS}}^{op}
\text{ is infinite }+.
\]

但原 KLS 代数 \(A\) 是否 infinite \(+\) 仍未严格完成。

KLS Proposition 3.2 的 partial-resolution 控制按照其 conventions 是右 \(A\)-modules，因此直接对应 \(A^{op}\) 的 Gap-A 方向。

所以不能据此说原 \(A\) 也 infinite \(+\)。

当前最有希望的镜像路线：

设
\[
A=\operatorname{End}_{\Lambda}(M),
\qquad
M=\Lambda\oplus N,
\]
并考虑
\[
M^\vee=\operatorname{Hom}_{\Lambda}(M,\Lambda).
\]

利用 gendo-Gorenstein / double-centralizer 思想，尝试建立：
\[
A^{op}
\simeq
\operatorname{End}_{\Lambda^{op}}(M^\vee)
\]
以及相反方向的 Chen partial-resolution / singular quotient。

如果这条镜像 quotient 能闭合：

- 可能证明原 \(A\) 也是 infinite \(+\)；
- 或者如果失败，可能暴露原 \(A\) 是 Gap-A counterexample。

因此：
\[
\boxed{
\textbf{KLS original-}A\textbf{ direction is a high-priority test.}
}
\]
