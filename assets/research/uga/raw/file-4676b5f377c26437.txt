# 韩猜想 → Universal Gap A：数学研究全过程历史档案

**时间范围：2026-08-08 — 2026-10-01**  
**项目：有限维代数 / Han 猜想 / Gap A–Gap B / Universal Gap A**  
**文档类型：研究过程史（不是最终论文，也不是只列定理的结果表）**

> 本文件按时间记录：当时遇到什么问题 → 为什么原路线不够 → 产生什么新想法 → 引入什么数学工具 → 哪些结论后来被修正/推翻 → 如何进入下一阶段。

## 0. 总主线

整个项目最初从 Han 猜想反例出发，逐渐演化成对 Universal Gap A 的长期研究。

最早的问题是：

\[
\text{KLS 的 Han 反例为什么能让 }HH_{n>0}\text{ 全部消失？}
\]

随后用 CLMS / Armenta 的语言把 Han 猜想拆成：

\[
\operatorname{gldim}A=\infty
\overset{\mathrm{Gap\ A}}{\Longrightarrow}
A\text{ infinite }+
\overset{\mathrm{Gap\ B}}{\Longrightarrow}
HH_*(A)\text{ infinite}.
\]

于是研究逐步变成：

\[
\boxed{
\text{Universal Gap A: }
\operatorname{gldim}A=\infty
\Longrightarrow
A\text{ infinite }+ \; ?
}
\]

主路线的历史演化大致是：

\[
\boxed{
\text{KLS}
\to
\text{Gap A/B 分类}
\to
\text{Serre–Probe}
\to
\text{有限顶点实验}
\to
\text{eventual periodicity}
\to
\text{vertex deletion}
\to
\text{derived deletion}
\to
\text{Rees torsion}
\to
\text{four-vertex FORK}
\to
\text{U1--U8 universal layer}.
}
\]

研究过程中越来越清楚的一件事是：

> 真正困难的不是制造“无限同调复杂度”，而是证明这种复杂度一定能被压缩成一个固定的、ordinary、simple-to-simple、Peirce-visible 的无限 Tor/Ext 通道。

后来的绝大多数工具，实际上都在解决这个 **visibility / alignment problem**。

# 1. 2026-08-08 起：从 Han 猜想反例开始

Kong–Liu–Shen 构造了有限维代数 \(A_{\mathrm{KLS}}\)，满足

\[
\operatorname{gldim}A_{\mathrm{KLS}}=\infty,
\qquad
HH_n(A_{\mathrm{KLS}})=0
\quad(n\ge1).
\]

因此 Han 猜想本身已经出现反例。

项目没有停在“知道反例”这一层，而是提出更细的问题：

- 这个反例是在哪一道机制上失败？
- infinite global dimension 本身是否仍会强迫某种可见的 recurrent simple homology？
- Hochschild homology 为什么没有捕获它？

这促使项目接受 CLMS / Armenta 的 Gap A / Gap B 分解。

---

# 2. 8 月中旬：KLS opposite algebra 与 terminal detector

最初的重要对象之一是

\[
B=A_{\mathrm{KLS}}^{op}.
\]

利用 KLS 的 partial resolution、stable Hom、eventual periodicity 等结构，项目发展出一套内部候选机制：

\[
\text{stable / singular detector}
\to
\text{infinite projective tail}
\to
\text{simple return}.
\]

这一时期形成的重要工具包括：

- Stable-Hom periodic detector；
- stable-to-actual syzygy transfer；
- partial-resolution / terminal detector；
- infinite-pd simple argument；
- periodic simple-return criterion。

阶段性内部判断曾是：

\[
B=A_{\mathrm{KLS}}^{op}
\text{ is infinite }+.
\]

这使项目一度倾向于把 KLS 看作 Gap B failure。

但这个判断后来必须被重新解释，因为左右模和 opposite algebra 的方向不能混用。

# 3. 8 月 15–18 日：Serre–Probe / Nakayama–Serre 统一框架

研究开始从 KLS 特例抽象出去。

取最小 \(A^e\)-projective resolution

\[
P_\bullet\to A
\]

并考虑 Nakayama-twisted complex

\[
K_\bullet=\nu_{A^e}(P_\bullet).
\]

利用已有文献结果：

\[
H_n(K_\bullet)
\cong
\operatorname{Tor}_n^A(DA,DA)
\cong
D\operatorname{Ext}_{A^e}^n(A,A^e),
\]

同时

\[
Z_n(K_\bullet)=\tau_nA.
\]

项目又得到链级关系：

\[
\operatorname{Hom}_{A^e}(DA,K_\bullet)
\cong
A\otimes_{A^e}P_\bullet.
\]

由此形成统一解释：

- Gap A：singular / Nakayama tail 是否能被 probe 看见；
- Gap B：已经被看见的 \(\tau\)-cycle 是否能在 ordinary Hochschild homology 中存活。

这一步把 Han 猜想从“一个同调消失问题”改写成：

\[
\boxed{\text{visibility problem}.}
\]

这成为整个后续研究的理论背景。

---

# 4. 同期：有限顶点实验室出现

项目开始测试：

\[
|Q_0|=1,2,3,4,\dots
\]

目的是不直接硬攻 arbitrary \(N\)，而是在最小规模上找出真正障碍。

阶段状态逐渐变为：

- \(1\)、\(2\) 顶点：高置信度闭合；
- \(3\) 顶点：形成 candidate theorem；
- \(4\) 顶点：出现 finite-hub / multi-top obstruction。

四顶点暴露出一个以后反复出现的结构：

> persistent homological source、recurrent detector、Peirce-visible carrier 不一定是同一个顶点。

这就是后来 U6/U7 “三角色错位”的早期形式。

# 5. 8 月 18–23 日：重大纠错——\(A^{op}\) 的 infinite+ 不能偷换成 \(A\) 的 infinite+

这是整个项目第一次非常关键的方向修正。

正确的 opposite-side relation 是：

\[
\Lambda\text{ infinite co}+
\iff
\Lambda^{op}\text{ infinite }+.
\]

并不是：

\[
\Lambda\text{ infinite }+
\iff
\Lambda^{op}\text{ infinite }+.
\]

因此即使证明了

\[
A_{\mathrm{KLS}}^{op}\text{ infinite }+,
\]

最多只能推出

\[
A_{\mathrm{KLS}}\text{ infinite co}+.
\]

不能推出原代数

\[
A_{\mathrm{KLS}}\text{ infinite }+.
\]

于是 KLS 的 Gap A / Gap B 分类被正式重新打开。

从此 KLS original-\(A\) 成为一个必须单独审计的问题：

\[
\boxed{
A_{\mathrm{KLS}}\text{ infinite }+\;?
}
\]

这一步也建立了长期规则：

- 必须区分 left / right；
- 必须区分 \(A\) 与 \(A^{op}\)；
- 必须区分 \(+\) 与 co\(+\)。

# 6. Eventual periodicity 路线

若

\[
\Omega_{A^e}^{N+p}A
\cong
\Omega_{A^e}^{N}A,
\]

则高阶 module syzygies受到 period 控制。

这一度给人很强的希望：

\[
\text{periodic}
\Rightarrow
\text{recurrent}
\Rightarrow
\text{infinite }+.
\]

但项目很快发现真正缺口：

\[
\boxed{
\text{singular/Tate recurrence}
\not\Rightarrow
\text{ordinary simple Ext recurrence}.
}
\]

尤其 non-Gorenstein 情形，不能把 singular category 或 Tate Ext 中的周期类直接当成 ordinary Yoneda algebra 中的 simple class。

因此形成长期禁令：

> 不把 singular/Tate recurrence 偷换成 ordinary Ext/Tor。

---

# 7. Periodic module self-extension

一个稳定资产是：

若 nonprojective module \(M\) 满足

\[
\Omega^pM\cong M,
\]

则存在

\[
\vartheta\in\operatorname{Ext}_A^p(M,M)
\]

且

\[
\vartheta^k\neq0
\in
\operatorname{Ext}_A^{kp}(M,M).
\]

这个工具证明 periodic module 确实带有永久 self-extension。

但项目也发现：

\[
\text{periodic module}
\not\Rightarrow
\text{periodic simple quotient}.
\]

把 module-level recurrence 降到 simple-level recurrence 时，会受到：

- multi-top；
- composition factors；
- \(A_\infty\) correction；
- comparison-map cancellation；

的阻碍。

---

# 8. Vertex-Deletion Descent

为处理“某个顶点高阶从不 return”，项目引入：

\[
C_x=A/Ae_xA.
\]

在 hypothetical Gap-A failure 中，如果

\[
\operatorname{pd}S_x=\infty,
\]

则得到重要工具：

\[
\boxed{
\operatorname{gldim}C_x=\infty.
}
\]

思想是：

> 如果顶点 \(x\) 自己永远不可见，就删除它，逼迫无限同调复杂度进入更小代数。

这是项目第一次真正获得“最小反例 / 无穷递降”式 universal 工具。

但马上出现新的问题：

\[
A\to A/AeA
\]

通常不是 homological epimorphism。

因此 quotient 中的 infinite+ witness 不能无条件 lift 回原代数。

这直接导致后来的 derived deletion。

---

# 9. Idempotent quotient 的第一层刚性

对于

\[
C=A/AeA
\]

以及任意 \(C\)-module \(M\)，项目确认：

\[
\boxed{
\operatorname{Tor}_1^A(C,M)=0.
}
\]

因此 deletion-created defect 只能从

\[
q\ge2
\]

开始。

这成为后来 spectral sequence / derived quotient 分析中的固定输入。

---

# 10. Bounded Deletion-Defect Forcing

项目进一步得到：

若 \(M,N\) 是 \(C\)-modules，且

\[
\operatorname{pd}_A M=d<\infty,
\]

同时 quotient 上有 arbitrarily-high Ext，则存在某个有限层

\[
2\le q\le d
\]

使

\[
\operatorname{Tor}_q^A(C,M)
\]

本身承载 persistent / infinite-pd defect。

因此形成一种非常重要的研究模板：

\[
\boxed{
\text{transfer 失败}
\Rightarrow
\text{失败本身产生新的 homological defect}.
}
\]

这以后反复出现在：

- deletion；
- quotient comparison；
- kernel absorption；
- Postnikov obstruction；
- Rees torsion。

# 11. 三顶点实验：singleton-tail / third-vertex return

三顶点 hypothetical failure 被压缩成非常具体的结构。

高阶 projective tail 可能最终集中为：

\[
P_n\cong (Ae_a)^{m_n}.
\]

同时存在：

\[
e_bAe_a=0,
\]

而第三顶点 \(h\) 提供绕行：

\[
e_aAe_hAe_a\neq0.
\]

于是核心问题变成：

> 第三个顶点的 through-path 是否会强迫真正的 supported homological return？

这里项目得到一个重要负面认识：

\[
\boxed{
\text{graph cycle}
\not\Rightarrow
\text{homological return}.
}
\]

从此明确禁止“裸 graph cycle ⇒ Yoneda/Tor return”。

这条禁令后来一直保留到 U7/U8。

# 12. 四顶点 finite-hub：multi-top derangement

四顶点出现新的有限 hub：

- infinite-pd source；
- recurrent top；
- finite-pd hub；
- Peirce carrier；

可以分散在不同位置。

一个 recurrent detector \(r\) 可以给出 persistent simple source \(b\)，但 hypothetical failure 强迫：

\[
e_bDe_r=0.
\]

另一方面，因为 \(b\) 是某个 module 的 composition factor，又会存在另一个 top carrier \(y\) 满足：

\[
e_bDe_y\neq0.
\]

于是产生：

\[
\boxed{
\text{detector 与 visible carrier 错位}.
}
\]

这后来演化成 U6 的 Bi-Singular Source Fork。

# 13. 9 月下旬：从固定小顶点向 arbitrary \(N\) 推进

# 16. Two-stage bar model

在局部模型中，相对 bar differential 被拆成：

\[
b=b_2+b_3,
\]

并满足：

\[
b_2^2=b_3^2=b_2b_3+b_3b_2=0.
\]

这里：

- \(b_2\) 是较基础的 differential；
- \(b_3\) 记录 cubic / derived correction。

问题变成：

> zero-column recurrence 会不会一直被越来越高 page 的 \(b_3\)-correction 杀死？

# 17. Rees deformation 与 Page–Torsion correspondence

引入：

\[
\mathcal B=(B[t],D=b_2+t b_3).
\]

得到关键思想：

> page-\(r\) differential 对应 Rees homology 中 exact \(t\)-torsion order \(r\)。

即：

\[
\boxed{
\text{high-page screening}
\Longleftrightarrow
\text{high-order }t\text{-torsion}.
}
\]

这样 spectral-sequence 问题被转换成 module-theoretic torsion growth 问题。

---

# 18. Uniform torsion bound

如果 high-degree Rees homology 的 \(t\)-torsion exponent 有统一上界，那么 sufficiently high zero-column classes 必须 survive。

因此 hypothetical failure 必须制造：

\[
\boxed{
\text{arbitrarily large exact torsion orders}.
}
\]

这把 Universal Gap A 的一部分前沿压缩成：

> 一个有限维 ordinary algebra 是否能无限地产生越来越高阶的 derived torsion，同时永远不产生 visible return？

---

# 19. Cycle-lift obstruction tower

尝试构造：

\[
U(t)=\sum_{m\ge0}t^mU_m
\]

满足：

\[
\partial_2U_0=0,
\qquad
\partial_2U_{m+1}=-\partial_3U_m.
\]

第 \(m\) 步 obstruction：

\[
[\partial_3U_m]
\in
H(\operatorname{End}(B),\partial_2).
\]

由此形成：

\[
\boxed{\text{Cycle-Lift Obstruction Tower}.}
\]

这一步的价值是：

不再模糊地问“cycle 能不能一直 survive”，而是逐层记录它为什么不能被 lift。

# 20. Primitive high-order torsion quotient

为了分离真正的新高阶 torsion block，项目定义类似：

\[
F_NT=\{x:t^Nx=0\},
\]

以及 primitive quotient

\[
\Pi_{>N}(T)=T/(tT+F_NT).
\]

对于

\[
T\cong\bigoplus_i k[t]_{(t)}/(t^{e_i}),
\]

有：

\[
\dim_k\Pi_{>N}(T)
=
\#\{i:e_i>N\}.
\]

因此持续 high-page death 不只是“同一个 torsion 被重复使用”，而是强迫不断产生新的高阶 primitive torsion blocks。

# 25. U3：First-Defect Bootstrap 被反例推翻
