# Universal Gap A — Codex Project

This folder is designed to be opened directly as the Universal Gap A Codex workspace.

## What is already external
- MRS is already built into Codex.
- The Obsidian mathematical Vault already exists in its own folder and is accessed through the installed Vault Skill.
- Human-facing HTML is generated by ChatGPT, not Codex.

## Start
Codex should read:
1. `AGENTS.md`
2. `CURRENT_STATE.md`
3. relevant entries in `claims/CLAIMS.md`

Then continue the current mathematical frontier.

## Repository roles
- `CURRENT_STATE.md` — current-state semantic authority
- `claims/CLAIMS.md` — small ledger of load-bearing claims
- `runs/` — append-only research trace
- `toolbox/` — curated reusable project assets
- `history/` — long-form provenance and route evolution
- `DECISIONS.md` — only durable project-management decisions
- `REGRESSION_GATES.md` — known logical traps checked during normal audit
- `proofs/` — substantial proof packages
- `references/` — source/file references that could not be embedded elsewhere

Do not treat this README as mathematical authority.
